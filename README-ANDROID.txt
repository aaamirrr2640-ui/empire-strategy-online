QRTT - Android build with AndroidIDE

1) Install AndroidIDE on the phone.
2) Extract this ZIP.
3) In AndroidIDE choose Open Project and select the qrtt folder (the folder containing settings.gradle).
4) Let Gradle download/sync dependencies.
5) Build > Assemble Debug (or Run).
6) The APK will be generated under app/build/outputs/apk/debug/.

For Google Play, create a signed release AAB from the AndroidIDE signing/build menu.
